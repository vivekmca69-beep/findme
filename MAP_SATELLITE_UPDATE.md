# Map satellite update

- Added **Map / Satellite** switch directly on the map.
- Street mode uses OpenStreetMap.
- Satellite mode uses Esri World Imagery plus an Esri boundaries/places label overlay.
- No Google Maps API key is required for the basemap switch.
- Moved FindMe full-screen/recenter controls to the top-right.
- Leaflet zoom remains bottom-right, so the controls no longer overlap.
- On narrow phones, the active-session card moves below the map-type selector and the custom controls move below the session card.
